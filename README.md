# For Google Bookmarks

> [!WARNING]
> **This project is archived.** It is no longer maintained, and no further updates, bug fixes, or support will be provided. Feel free to fork it if you want to continue development.

A browser extension for [Google Bookmarks](https://www.google.com/bookmarks/).

## Development

```sh
npm install
npm run watch        # development build with watch mode
npm run build        # production build
npm test             # run tests
```

The Node.js version is pinned in `.nvmrc`.
